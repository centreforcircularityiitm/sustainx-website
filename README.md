# SustainX 2026: Circularity in Energy, Earth and Environment

Official repository for the **SustainX 2026** international conference, hosted at **IIT Madras** (July 23 - 25, 2026). This platform serves as the central hub for researchers, industry experts, and policymakers focusing on circular economy innovations in energy, earth, and environmental sciences.

## 🌐 Live Website
**[https://sustainxconference.org](https://sustainxconference.org)**

---

## 🚀 Technical Highlights

This project is engineered for high performance, institutional security compliance, and premium editorial aesthetics.

- **Design System**: Built with **Tailwind CSS v4** utilizing custom fluid design tokens for typography and spacing, ensuring a consistent and professional experience across all viewports.
- **Performance**: Optimized for speed with semantic HTML5, localized assets, and clean vanilla CSS integrations.
- **Security**: Implemented advanced security headers (OWASP A02:2025 compliant), including:
    - `Content-Security-Policy` (CSP)
    - `X-Content-Type-Options: nosniff`
    - `X-Frame-Options: SAMEORIGIN`
- **SEO & Social**: 
    - Full metadata suite for high visibility on Google and social media.
    - Custom-engineered Open Graph cards for WhatsApp, LinkedIn, and X.
    - Automated `sitemap.xml` and `robots.txt` for efficient search indexing.
